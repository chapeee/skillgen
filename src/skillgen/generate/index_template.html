Routes without a form

Using a skill

  1. Copy a skill folder into Claude or Cowork (or upload it as a zip in Skills settings).
  2. Ask Claude to fill the page; it reads SKILL.md and fills the form in one browser call.
  3. Nothing else to install: the built-in browser is enough.
